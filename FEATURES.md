# Features & Roadmap

## ✅ Current Features (v1.0)

### Admin Portal
- ✅ Magic link authentication (passwordless)
- ✅ Dashboard with all wedding cards
- ✅ Create/Edit/Delete wedding invitations
- ✅ Design customization (colors, fonts)
- ✅ Live preview
- ✅ Publish/Unpublish cards
- ✅ Copy shareable link
- ✅ Track RSVP count

### Guest Experience
- ✅ Beautiful responsive invitation card
- ✅ Indian wedding theme with gradients
- ✅ RSVP form with validation
- ✅ Custom question support
- ✅ Dietary restrictions field
- ✅ Personal message to couple
- ✅ Attending/Not attending options
- ✅ Guest count selection
- ✅ Background music support

### Email System
- ✅ Magic link emails for admin login
- ✅ RSVP notification emails (to 3 addresses)
- ✅ Beautiful HTML email templates
- ✅ Gmail SMTP integration

### Technical
- ✅ Next.js 14 with App Router
- ✅ TypeScript
- ✅ PostgreSQL database
- ✅ Prisma ORM
- ✅ Docker Compose setup
- ✅ Tailwind CSS styling
- ✅ Shadcn/ui components
