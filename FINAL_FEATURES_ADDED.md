### 3. ✅ **Layer Controls (Z-Index)**
**4 layering options** in properties panel:

**Buttons:**
- **⬆️ To Front** - Bring element to very front
- **⬇️ To Back** - Send element to very back
- **↑ Forward** - Move up one layer
- **↓ Backward** - Move down one layer

**How it works:**
- Each element has a z-index value
- Higher z-index = appears on top
- Lower z-index = appears behind
- Select element → Use layer buttons

**Use cases:**
- Put text on top of images
- Layer decorative elements
- Control overlapping elements
- Create depth in design
