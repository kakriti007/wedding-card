## 🎯 How to Use the Improved Editor:

### **Moving Elements:**
1. Click an element to select it (purple ring appears)
2. Drag it anywhere on the canvas
3. Elements snap to 10px grid for alignment
4. Drop when positioned correctly

### **Editing Text:**
1. Click a text element to select
2. Click it again to enter edit mode
3. Type your changes
4. Click outside to save (or press Enter)
5. Press Escape to cancel

### **Deleting Elements:**
- **Method 1:** Select element → Press Delete key
- **Method 2:** Select element → Click trash icon in right panel

### **Styling Elements:**
1. Click element to select
2. Right panel shows all style options
3. Change font size, color, alignment, etc.
4. Use X/Y inputs for precise positioning

### **Managing Pages:**
- Add page: Click [+] in left panel
- Switch page: Click page name
- Duplicate: Click copy icon
- Delete: Click trash icon (must have 2+ pages)

### **Background Customization:**
1. Click empty area on canvas (deselect all)
2. Right panel shows background options
3. Choose: Solid Color / Gradient / Image
4. Adjust colors or upload image
