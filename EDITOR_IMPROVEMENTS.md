# Editor Improvements Needed

## Issues with Current Editor:

1. **Drag offset calculation** - Elements jump when you start dragging
2. **Selection feedback** - Hard to see what's selected
3. **Canvas scrolling** - Canvas should be fixed size, not scrollable
4. **Element z-index** - Elements can overlap confusingly
5. **Double-click edit** - Not intuitive for users
6. **No undo/redo** - Can't reverse mistakes
7. **No snap-to-grid** - Elements don't align nicely
8. **Image sizing** - Images don't maintain aspect ratio

## Quick Fixes Implemented:

### 1. Better Drag Behavior
- Fixed offset calculation
- Smoother dragging
- Better bounds checking

### 2. Visual Improvements
- Thicker selection border
- Hover effects
- Better element outlines

### 3. Usability
- Click to edit text (not double-click)
- Better button placement
- Clearer instructions

## Alternative Approach:

Instead of building a full Canva clone (which is complex), consider:

### **Template-Based Approach:**
1. Provide 5-10 pre-designed templates
2. Users can only customize:
   - Colors
   - Text content
   - Upload couple photo (replaces placeholder)
   - Swap background images

### **Benefits:**
- Much easier to use
- Professional results guaranteed
- Faster card creation
- Mobile-friendly
